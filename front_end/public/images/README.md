# SGU branding assets

`sgu-logo.webp` and `sgu-favicon.webp` are the original logo and favicon supplied by the reference website, downloaded without modification for this project's requested SGU styling.

Source: https://thongtindaotao.sgu.edu.vn/#/home

The images are returned in the `logo` and `favicon` fields of the site's public `api/web/w-locdssettingtruong` response. Brand ownership remains with Trường Đại học Sài Gòn.
